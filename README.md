# PulseLink Studio

A static GitHub Pages build of the PulseLink Studio creator editor.

Open `index.html` locally or publish this repository with GitHub Pages. The editor runs in the browser and stores its workspace in local browser storage. Server-backed authentication, database, payment, and API routes from the separate Next.js architecture package are not part of this static Pages deployment.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save. GitHub will provide the site URL in the Pages settings.
